# PicardWulf v1.0

**Пошук релізів із багатьох джерел, автоматичний вибір метаданих і безпечне збереження тегів для MusicBrainz Picard 3.0.**

> **Стан:** тестова версія. Локальні тести успішні, але запуск на BMAX-B6, реальні API та збереження аудіофайлів ще не перевірені.

## Можливості

- Об’єднаний пошук у MusicBrainz, Deezer та Apple/iTunes; Spotify, SoundCloud і Last.fm підтримуються за наявності дозволених API-ключів.
- Після **Додати теку** релізи оцінюються за назвою, виконавцем, альбомом, тривалістю та справжніми ідентифікаторами.
- **Перемагає найкращий за балами реліз**, навіть якщо джерело — Deezer, Spotify чи інша платформа, а не MusicBrainz.
- Суперечливі ідентифікатори, різні видання й майже однакові бали потребують ручної перевірки.
- У стандартному вікні альбомів Picard допускаються лише справжні пари MBID релізу й запису MusicBrainz. Зовнішні ID не підмінюють MBID.
- Автоматичний вибір спершу змінює тільки метадані в Picard. **Автоматичне збереження аудіо вимкнено** за замовчуванням; після окремого ввімкнення повна резервна копія кожного файлу перевіряється SHA-256.
- Правила NEOWULF збережено. Помилкове віднесення сольних збірок до Various Artists виправлено; *Curtain Call 2* залишається альбомом Eminem.

## Встановлення

Закрийте Picard **3.0**, розпакуйте архів та запустіть **`Install-NEOWULF.cmd`** у сеансі власника робочого столу (`megal` на BMAX-B6). Каталог: `%APPDATA%\MusicBrainz\Picard\plugins3\neowulf_picard_repair`. Несправний `picard-cli.exe` не використовується. Увімкніть плагін у **Options → Plugins**.

## Використання та безпека

**File → Add Folder** запускає пошук; **Tools → PicardWulf** дає вибір джерела та необов’язкове збереження з резервною копією; **Tools → NEOWULF** показує стан і налаштування назв. Автозастосування потребує однозначного результату щонайменше **93,5 %**. Пошукові запити надсилаються лише дозволеним постачальникам із дотриманням обмежень API. Перевірка на BMAX-B6 ще потрібна.

## v1.0 S2 — стан вихідного коду

Додано дозволи для джерел, стани доступності, постійні ліміти й очікування та безпечну роботу з токенами. Незавершені відповіді не запускають автоматичні зміни. Анонімні перевірки MusicBrainz/Deezer/iTunes і 145 тестів пройдено; авторизовані джерела та роботу на BMAX ще не підтверджено. Нові підписки не створюються.
