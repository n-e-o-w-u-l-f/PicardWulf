# PicardWulf v1.0

**Поиск релизов из нескольких источников, автоматический выбор метаданных и безопасная запись тегов для MusicBrainz Picard 3.0.**

> **Статус:** версия для проверки. Локальные тесты выполнены, но запуск в Picard на BMAX-B6, реальные ответы API и сохранение тегов в Windows ещё требуют проверки.

## Возможности

- **Общий поиск:** MusicBrainz, Deezer и каталог Apple/iTunes; Spotify, SoundCloud и Last.fm доступны при наличии разрешённых API-учётных данных.
- **После «Добавить папку»:** обработка файлов в фоне и единый рейтинг релизов по исполнителю, названию, альбому, длительности и подтверждённым идентификаторам.
- **Побеждает лучший результат:** источник не обязан быть MusicBrainz. Если Deezer, Spotify или другой сервис набрал больше обоснованных баллов, его результат становится выбранным источником метаданных.
- **Проверка конфликтов:** неоднозначные релизы, несовпадения исполнителей, ISRC и разные издания остаются на ручную проверку.
- **Штатное окно альбомов Picard:** для загрузки собственного релиза Picard используются только настоящие идентификаторы MusicBrainz Release и Recording. Идентификаторы других платформ не подменяют MBID.
- **Теги и резервные копии:** автоматический выбор по умолчанию меняет только метаданные в Picard. Автоматическая запись аудиофайлов **выключена**; при явном включении перед каждым сохранением создаётся полная резервная копия с проверкой SHA-256.
- **NEOWULF:** сохранены правила имён файлов и исправление ошибочного отнесения компиляций к Various Artists. *Eminem — Curtain Call 2* остаётся в разделе Eminem.

## Установка в Windows

1. Закройте MusicBrainz **Picard 3.0**, предварительно сохранив свою работу.
2. Распакуйте проект или пакет релиза.
3. Запустите **`Install-NEOWULF.cmd`** под владельцем рабочего стола (на BMAX-B6 — `megal`); не запускайте неподписанный `.ps1` непосредственно.
4. Файлы устанавливаются в `%APPDATA%\MusicBrainz\Picard\plugins3\neowulf_picard_repair` без использования неисправного `picard-cli.exe`.
5. Откройте Picard и включите плагин в **Options → Plugins**.

## Использование

Команда **File → Add Folder** запускает поиск. В меню **Tools → PicardWulf** доступны автоматический выбор релиза, отдельное включение записи тегов с резервными копиями и ручной просмотр. Меню **Tools → NEOWULF** содержит состояние источников, учётные данные, результаты и исправление шаблона имён.

Для автоматического применения нужен однозначный релиз с оценкой не ниже **93,5 %** и достаточным отрывом от конкурентов. Данные, угаданные только по имени файла, автоматически не применяются.

## Безопасность и ограничения

Доступность сервисов и API зависит от их правил. Поисковые поля отправляются включённым поставщикам метаданных; обход ограничений API не применяется. Сторонний релиз можно выбрать в PicardWulf, но он **не выдаётся за релиз MusicBrainz** в штатном окне Picard. Асинхронное сохранение следует проверять по итоговому состоянию файла.

## Разработка

```bash
python -m unittest discover -s tests -v
```
