# PicardWulf v1.0 — provider completeness for newly added tracks

2026-10-14 | Source-only checkpoint, not BMAX runtime acceptance.

## Confirmed source defect
An album-local cache hit from a sibling recording could return LOCAL_CACHE from UniversalAggregator._work before checking any eligible provider for the new recording. With no current provider checkpoints, Python's all(empty) was true. A separate early-exit skipped Last.fm if an earlier MusicBrainz/Deezer candidate already scored well.

## Corrected contract
- The album-local cache remains edition/tracklist *supporting evidence*, never evidence that a particular provider was searched for this new recording.
- Every enabled and credential-authorized source is independently queried or reuses a completed checkpoint or provider-specific response cache for the **exact canonical recording query**.
- A good MusicBrainz candidate no longer suppresses Deezer, SoundCloud or Last.fm requests when those providers are eligible. All remain rate-limited and subject to persistent retry and explicit restricted/credential states.
- Streaming service provider IDs cannot be interpreted as MusicBrainz release IDs. Ambiguous editions abstain; no original audio is saved by these search changes.
- This broadens network requests and can increase total processing time for 39,000 files, but does not increase concurrency or block Qt with new I/O.

## Regression and verification
Four new tests in tests/test_provider_completeness.py: album-cache short-circuit and Last.fm omission reproduced RED then fixed GREEN; legitimate synthetic SoundCloud token competing with Deezer/MusicBrainz, and completed MusicBrainz checkpoint reuse. 180 offline Legion tests passed including the 41-case S3 release corpus. Synthetic SoundCloud credentials do **not** demonstrate access to a live SoundCloud developer app.

## Outstanding gates

Valid Spotify/SoundCloud/Last.fm credentials and their current permissions remain unverified. The full tag-save/rollback S4 and Windows acceptance S5 are OPEN. The target stays **v1.0**.
